## Addy 5.1.0 contract migration

[`addyosmani/agent-skills@e997ac5b9a74eab332d5e9793bb38a38c8cfdd74`](https://github.com/addyosmani/agent-skills/commit/e997ac5b9a74eab332d5e9793bb38a38c8cfdd74),

### Upstream changes in the closure

- `accessibility-engineering` (new skill) audits existing interfaces for WCAG
  2.2 AA and remediates verified violations. Its tree includes the executable
  `scripts/audit-a11y.sh` (mode 0755) and a skill-local accessibility checklist.
- `agents/accessibility-auditor.md` (new role) and `commands/a11y.toml` (new
  command) add a dedicated accessibility audit.
- Upstream now ships generated byte-exact copies of the shared
  `references/*.md` checklists inside each consuming skill under
  `references/shared/`, and its skills link to those copies instead of
  `../../references/`.
- `constraint-driven-development` adds `scripts/quality-gate.mjs` and reports
  floor-guard findings by file and line.
- `commands/build.toml` and `commands/spec.toml` add delta specs
  (`SPEC-<change>.md`) and a `Source spec:` plan guard;
  `commands/planning.toml` can defer the task list to a designated issue
  tracker.
- Wording and guidance changes across 25 skill trees and four shared
  checklists, including Spec Evolution, documentation drift, OWASP 2025
  renumbering, review evidence checks, Node 24 CI examples and sharper trigger
  descriptions. The four existing role documents and `LICENSE` are unchanged.

### Decisions

- **Former reference adaptations become exact copies.** The 11 skills that the
  catalog adapted only to rewrite `../../references/` links and carry
  skill-local copies (`code-review-and-quality`, `doubt-driven-development`,
  `frontend-ui-engineering`, `incremental-implementation`,
  `observability-and-instrumentation`, `performance-optimization`,
  `planning-and-task-breakdown`, `security-and-hardening`,
  `shipping-and-launch`, `test-driven-development`, `using-agent-skills`)
  are now self-contained upstream. They are declared `exact-copy` of the new
  trees; the catalog's `references/<name>.md` copies are removed in favor of
  upstream's `references/shared/` files.
- **Claude variant retired.** The `using-agent-skills-claude` source existed
  only so the Claude composition's `references/definition-of-done.md` did not
  collide with the source copy. The upstream copy now lives at
  `references/shared/definition-of-done.md`, so both surfaces use the one exact
  tree and the variant is removed.
- **Supporting assets.** The seven `assets/` remain exact copies of upstream
  `references/` at the new commit, and every existing composition keeps all
  seven as `references/` on Claude.
- **New resources.** `accessibility-engineering` is an exact copy with native
  Agents and Claude bindings and no dependencies, like the other self-contained
  workflow skills. Its `../frontend-ui-engineering/SKILL.md` and
  `../../agents/accessibility-auditor.md` mentions are informational code spans
  and are kept byte-exact. `accessibility-auditor` follows the
  `web-performance-auditor` contract (Codex global role, Claude global/project
  role with the same authority map and `using-agent-skills` dependency), with
  `/a11y` rewritten as the `a11y` skill and the `docs/agents.md` link pinned
  to the new commit. `a11y` is an adapted skill derived from
  `commands/a11y.toml` like `webperf`: it stops when the named role or
  delegation is unavailable and has a Claude composition with the role,
  `accessibility-engineering`, `using-agent-skills` and all seven assets.
- **Command adaptations.** `build`, `plan` and `spec` port the upstream
  command changes while keeping the catalog's skill invocation wording.
  The four existing role documents only re-pin their `docs/agents.md` link.
- **Descriptions.** `documentation-and-adrs` and `spec-driven-development`
  manifest descriptions follow their new drift and spec-evolution scope.
- **Plugin export.** Neither new skill is plugin-eligible; reasons are recorded
  in the [two-surface review](../research/addy-two-surface-review.md). Upstream
  evals, hooks, CI, scripts and `.claude`/`.gemini` command copies are outside
  the declared closure.

tooling suite passes all 74 tests with the three Pack helper execution
sentinels, and `git diff --check` passes.
