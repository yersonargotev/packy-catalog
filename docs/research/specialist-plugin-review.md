# Specialist Pack plugin review

This review covers the Argote, Orchestrate, and Thermos resources in the
coordinated two-surface generation. Direct bindings are not evidence that a
client loaded a role, authorized tools, or delegated work.

| Pack and skill | Agent Plugins | Claude plugin | Review |
| --- | --- | --- | --- |
| Argote `espera-que` | Unsupported | Eligible | Manual-only frontmatter is retained; Agent Plugins rejects it. |
| Argote `issue-delivery` | Unsupported | Unsupported | The reviewed workflow targets Codex and requires manual invocation plus externally installed Matty skills. |
| Orchestrate `orchestrate` | Eligible with Codex delegation prerequisite | Unsupported | The source addresses a Codex delegation interface; a shared Agents binding does not imply Claude compatibility. |
| Thermos review rubrics and `thermos` | Unsupported | Eligible | Manual-only frontmatter is retained. The coordinator requires both named reviewer roles, which are external plugin prerequisites. |

Thermos installs its named role definitions only through explicit Codex global
or Claude global/project projections. A project-scoped Agents selection that
requires these roles fails. A plugin contains no role definitions; the operator
must supply the named roles and authorize delegation separately. A missing role
or unavailable delegation is an incomplete review, never evidence of a
successful independent review.

The Addy resources are reviewed separately as part of the remaining cohort;
this inventory does not claim that the complete catalog is compatible.
